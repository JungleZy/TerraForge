## 问题修复

### 1. 滚动问题 ✅
**问题描述**：历史记录和配置页面无法滚动

**根本原因**：`.main-content` 设置了 `overflow: hidden`

**解决方案**：
```css
.main-content {
    overflow-y: auto; /* 允许垂直滚动 */
}
```

**影响页面**：
- ✅ 历史记录页（history.html）
- ✅ 配置页（config.html）

### 2. 任务列表样式不统一 ✅
**问题描述**：任务卡片样式与整体设计不统一

**解决方案**：
- ✅ 优化间距（margin-bottom）
- ✅ 统一字体样式
- ✅ 优化badge显示（inline-flex + gap）
- ✅ 统一进度条高度
- ✅ 优化progress-detail布局
