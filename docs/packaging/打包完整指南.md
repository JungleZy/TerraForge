## 🎯 快速开始

### 方式一：GitHub Actions 自动构建（推荐）

1. **推送代码到 GitHub**
   ```bash
   git push origin master
   ```

2. **创建版本标签触发构建**
   ```bash
   git tag -a v1.0.0 -m "首次发布"
   git push origin v1.0.0
   ```

3. **等待构建完成**
   - 访问你的 GitHub 仓库
   - 点击 "Actions" 标签
   - 查看 "Build Executables" 工作流
   - 等待约 15-30 分钟（三个平台并行构建）

4. **下载可执行文件**
   - 构建完成后，访问 "Releases" 页面
   - 下载对应平台的压缩包：
     - `terraforge-windows.zip` (Windows)
     - `terraforge-macos.tar.gz` (macOS)
     - `terraforge-linux.tar.gz` (Linux)

### 方式二：本地构建

```bash
# Linux/macOS
./build.sh

# Windows
build.bat

# 构建产物在 dist/terraforge/ 目录
```

## 🚀 使用流程

### 开发者（你）

1. **本地测试**（可选但推荐）
   ```bash
   ./build.sh
   cd dist/terraforge
   ./terraforge
   # 浏览器访问 http://localhost:5000 测试
   ```

2. **推送到 GitHub**
   ```bash
   git push origin master
   ```

3. **创建发布版本**
   ```bash
   git tag -a v1.0.0 -m "正式发布 v1.0.0"
   git push origin v1.0.0
   ```

4. **监控构建**
   - GitHub Actions 会自动构建
   - 查看构建日志确保成功
   - 检查 Releases 页面

### 最终用户

1. **下载**
   - 访问 GitHub Releases 页面
   - 下载对应平台的压缩包

2. **解压**
   - Windows: 右键 → 解压到文件夹
   - macOS/Linux: `tar -xzf terraforge-*.tar.gz`

3. **运行**
   - Windows: 双击 `terraforge.exe`
   - macOS/Linux: `./terraforge`

4. **使用**
   - 浏览器自动打开或手动访问 `http://localhost:5000`
   - 无需安装 Python 或任何依赖

## ⚠️ 注意事项

### 首次构建
- Windows 构建可能需要 20-30 分钟（GDAL 安装较慢）
- macOS 和 Linux 通常 10-15 分钟
- 如果构建失败，查看 Actions 日志调整配置

### 文件大小
- 每个平台的压缩包约 100-300MB
- 解压后约 300-500MB
- 这是正常的，因为包含了完整的 Python 运行时和所有依赖

### 用户端问题
- **macOS**: 首次运行可能提示"无法验证开发者"
  - 解决：`xattr -cr terraforge` 或在系统偏好设置中允许
- **Windows**: 可能被杀毒软件拦截
  - 解决：添加到白名单
- **Linux**: 可能需要添加执行权限
  - 解决：`chmod +x terraforge`

## 🔧 故障排除

### 构建失败

1. **查看 Actions 日志**
   - 点击失败的工作流
   - 展开失败的步骤
   - 查看错误信息

2. **常见问题**
   - GDAL 安装失败：调整对应平台的安装命令
   - 依赖冲突：检查 requirements.txt
   - 内存不足：减少并发或优化依赖

### 可执行文件无法运行

1. **检查日志**
   - 运行可执行文件时查看终端输出
   - 查找错误信息

2. **常见问题**
   - 找不到模块：添加到 build.spec 的 hiddenimports
   - GDAL 错误：检查 hook-gdal.py
   - 路径错误：检查 app.py 和 config.py 的路径处理
