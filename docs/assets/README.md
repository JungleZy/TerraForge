## ⚠️ 通用警告：本目录所有截图都不是当前基线

每一张都是**过去某个时点**的界面。拍完之后 UI 至少经历了这几轮整体改造：

- 单一时间流重构（三分区 / dock 式活动任务卡片被取代）
- dark / light / system 三态主题（拍摄时全是单一深色或单一浅色）
- 0.2.3 保存路径绝对化 + 目录浏览（截图里还是相对路径裸输入框）
- 0.2.4 缓存管理重做（截图里的「缓存最大大小 (MB)」配置项连同自动 LRU 清理已删除）

外加旧品牌名「Maps Downloader」（现为 TerraForge）散落在多张图里。

**失效的视觉基线不会让任何测试变红**——UI 约束走的是 CSS 文本断言（`tests/test_css_contract.py`），不做图像比对。所以这些图坏掉了也没人报警，只会安静地误导下一个照着它改界面的人。这正是它们比「根本没有截图」更糟的地方：没有图，人会去跑一遍应用；有过期的图，人会直接信。

要看当前界面，跑 `uv run python app.py` 自己截。
