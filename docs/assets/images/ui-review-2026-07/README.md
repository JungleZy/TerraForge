5 张实测截图，是 `../../../reviews/2026-07-27-ui-review.md`（界面与操作专业度评审）的证据附图，被该报告「2. 实测记录」一节**逐张内嵌引用**：

## 为什么不能当基线

拍的是**改造前**的形态——这份评审正是 `../../../superpowers/plans/2026-07-27-master-plan.md` 那轮改造的立项依据，图里所有被吐槽的问题就是后来要改掉的东西。其后 UI 又叠了好几轮：GIS 工作台改版、单一时间流、dark/light/system 三态主题、0.2.3 路径绝对化、0.2.4 缓存管理重做。今天的界面和这 5 张图没有可比性。

图里这些今天已不存在：旧品牌名、Leaflet 地图（现为 CesiumJS）、独立的历史/配置页导航（现为浮动按钮 + 侧滑覆盖面板）、相对路径的保存路径输入框、「缓存最大大小 (MB)」配置项。
