Two paths of a single tile

On download the engine asks the cache first: hits are copied into the artifact directory by the backfill thread, misses go through the semaphore to the upstream, get magic-byte checked, land in the cache and are then mirrored. Browsing takes the other path — the tile port passes whitelisted prefixes straight to the artifact directory.
