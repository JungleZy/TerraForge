## 性能优化

1. **CSS 优化**
   - 使用 CSS 变量减少重复
   - 硬件加速的动画（transform, opacity）
   - 避免昂贵的重排操作

2. **字体加载**
   - Google Fonts CDN
   - 仅加载需要的字重
   - `display=swap` 优化

3. **动画性能**
   - 使用 `will-change` 提示
   - 限制动画元素数量
   - 使用 CSS 动画而非 JS
