# docs/archive —— 历史文档归档

> **本目录里没有一份文件代表当前实现，任何一份都不能作为开发依据。**

## 三件必须先知道的事

1. **这是历史归档。** 每份文件记录的是它写下那天的状态。开发时请以下面「当前事实源」为准，不要照这里的内容改代码、改配置或写测试。
2. **正文一律保持原样未回改。** Tech Stack 行、基线数字、行号引用、复选框状态、命令示例全是当日快照——改掉等于伪造历史记录。所有「今天还成不成立」的信息只写在每份文件开头的状态头里。因此文件内部引用的路径可能指向已移动或已删除的位置，**这是有意保留的历史原貌，不是待修的死链**。
3. **归档不等于全错。** 有几份的结论今天仍然带电（比如「前端不做乐观更新」「轮询是被刻意删掉的」「暂停时不逐秒刷新」），状态头里会点名保留。删掉这些约束对应的代码，旧 bug 就会复活。
