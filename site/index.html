四条数据管线

从一个选区，长出四种产物

同一块区域、同一套任务调度、同一份缓存。选完范围之后，剩下的差别只是你要什么格式。

TILES / 地图瓦片

框选下载，拼成带地理配准的 GeoTIFF

从 Google Maps 取瓦片，边下边镜像到产物目录。要瓦片目录、要拼接好的 GeoTIFF、要单文件 MBTiles，勾选框自己组合。

样式
标准 m · 卫星 s · 卫星+标注 y · 道路 h · 地形 t
产物
瓦片目录 · GeoTIFF（按 zoom 一层一张）· MBTiles（建任务时勾选或事后导出，不删原瓦片）
缓存
按「样式 + 坐标」键控，跨任务共享 —— 换个任务重下同一片区，已有的瓦片不会再走一次网络

DEM / 高程数据

1°×1° 分幅高程，默认源不用注册账号

按你框的范围自动算出需要哪些分幅并逐个取回。默认走 Copernicus 的公开 S3 桶，开箱就能下；需要 ASTER 的话再去配 Earthdata。

默认源
Copernicus GLO-30（30 m，公开 S3 桶，免认证）
可选源
ASTER GDEM v3 ASTGTM.003（30 m，需 NASA Earthdata 账号，在配置页填）
选区
地图框选，或导入 GeoJSON / KML / KMZ / Shapefile，支持多部件与孔洞
跨经线
越过 180° 的区域自动拆成两段处理

TERRAIN / 3D 地形

切成 Cesium quantized-mesh，自带全球底座

把下载好的 DEM 或本地上传的 GeoTIFF 切成地形瓦片。包里随附一份全球基础地形，切片成果会植入它的输出目录 —— 相机拉远时不会掉进空洞。

格式
quantized-mesh 1.0，CesiumJS 直接消费
底座
随包 167 MB 全球基础地形（GEBCO 2024 Grid 派生，含海底地形、全球无洞），首次运行自动解压
级联
你的高精度切片盖在底座上，缩小时自动接回全球
输入
已下载的 DEM 任务，或本地上传的 GeoTIFF；无切片时也能按需渲染晕渲图预览

CONTOUR / 等高线

渲染成标准 XYZ 瓦片，谁都能加载

产物就是普通的 XYZ 瓦片目录，Leaflet、OpenLayers、CesiumJS 拿去直接用，不需要装 TerraForge 才能看。

产物
标准 XYZ 瓦片，Leaflet / OpenLayers / CesiumJS 直接加载
样式
等高距、首曲线与计曲线配色、分层设色断点、地形晕渲，逐项可调并支持预览
数据源
上传 .tif（可多选），或复用已完成的 DEM 任务 —— 源文件零拷贝，删等高线任务不动原 DEM

为什么不是又一个批量下载器

大任务真正的难处不在下载，在出问题之后

几万块瓦片跑一夜，第二天你需要知道的是：到底成了没有、缺了什么、能不能接着跑。这四件事是 TerraForge 花力气最多的地方。

进度是真的

WebSocket 推送下载速度、剩余时间，以及分 zoom 的拼接与复制阶段。进度条不会停在 100% 让你猜后面还在干什么。

缺块不静默

瓦片结果分五类记账：成功、本来无数据、可重试失败、永久失败、缓存写入失败。只有「本来就没数据」才自动完成；出现真失败会停在待决策等你拍板，而接受了缺口的成果永久带缺块标记。

断了能接上

断点续传、跨任务共享缓存、边下边复制、.part 临时文件加 rename 原子落盘。暂停、恢复、重试都不会重下已经拿到的瓦片。

不联网汇报

没有任何遥测、埋点或使用统计。前端第三方库全部本地 vendor，运行期不碰 CDN。除了你自己配置的图源、高程源与代理，它不连接任何服务器。

下载 TerraForge

三个平台的预编译包，解压就能跑，目标机器不需要 Python，也不需要单独装 GDAL。

Windows Windows 10+ · x64 terraforge-windows.zip ↓ macOS Apple Silicon · arm64 terraforge-macos.tar.gz ↓ Linux x64 · ubuntu-latest 同等或更新 terraforge-linux.tar.gz ↓
  • Windows 双击 terraforge.exe，macOS / Linux 跑 ./terraforge，然后浏览器打开 http://localhost:5000。程序另会监听 5001 出瓦片，防火墙不放行也能用。
  • 没有安装包，也没有自动更新。不做 MSI / DMG / DEB，换版本就是重新下一个包。
  • 每个包都含 167 MB 的全球基础地形分卷，所以体积偏大。Release 页面附 SHA-256 清单，可校验你手上这份是不是原版。
  • Intel Mac 不支持 —— macOS 包只有 Apple Silicon (arm64) 一种。
  • 移动位置时整个 terraforge/ 目录一起搬。只挪可执行文件会报 Corrupt bundle: missing GDAL/PROJ data directories。
  • macOS 首次运行前，在解压出来的目录里执行 xattr -cr . 清掉隔离属性。
  • 程序监听 0.0.0.0:5000 且没有任何登录或鉴权机制，其 API 能读写本机磁盘路径并删除目录。只在可信的本机或局域网里用，别直接暴露到公网。
